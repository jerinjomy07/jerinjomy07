  - Zero-drift mobile engineering & hardware-backed security (React Native / Expo / Android)
  - Deep Learning & Audio ML (BTC Transformers, Demucs stem separation, Librosa)
  - Clean UI/UX systems & ergonomic developer workflows
current_focus: Building intelligent, scalable, and cross-platform productivity software

* 🔭 **What I'm building:**
  * **[FocusFlow](https://github.com/jerinjomy07/Focus-Flow)**: Cross-platform productivity suite featuring drift-free monotonic timers, Android Keystore session cryptography, and real-time synchronization between Next.js 16 and React Native.
  * **[Song Chord Analyzer](https://github.com/jerinjomy07/Song-Chord-Analyzer)**: Real-time automatic chord recognition desktop app powered by PyTorch BTC Transformers, Demucs stem separation, Librosa DSP, and Electron + React 19.
* 💡 **What drives me:** Turning complex engineering challenges into clean, accessible software that solves real problems.
* 💬 **Ask me about:** React/Next.js, TypeScript, React Native mobile security, Python audio processing, or full-stack architectures.
